👥 API Clientes - Sage ACICloud

📋 Descripción

API para gestionar clientes en Sage ACICloud con sincronización automática, validación de RUC panameño y soporte multi-tenant.

🌐 Base URL

/api/acicloud/customers
🔐 Autenticación requerida: Bearer Token (Sanctum)
🔒 Middleware: check.activate.organization

📚 Endpoints Disponibles

POST Crear Cliente

Endpoint: /api/acicloud/customer

Crea un nuevo cliente con sincronización automática a Sage ACICloud.

Campos de Request

Campo Tipo Validación Descripción
CustomerID REQUERIDO string Máx. 20 caracteres, único ID único del cliente
Customer_Bill_Name REQUERIDO string Máx. 39 caracteres Nombre de facturación
AddressLine1 OPCIONAL string - Dirección línea 1
AddressLine2 OPCIONAL string - Dirección línea 2
City OPCIONAL string - Ciudad
State OPCIONAL string Máx. 2 caracteres Estado/Provincia
Zip OPCIONAL string Máx. 12 caracteres Código postal
Country OPCIONAL string - País
Telephone1 OPCIONAL string Máx. 20 caracteres Teléfono principal
Email OPCIONAL string Email válido, máx. 64 caracteres Correo electrónico
RUC OPCIONAL string Alfanumérico, máx. 40 RUC del cliente
DV OPCIONAL string Alfanumérico, máx. 40 Dígito verificador
Custom_field3 OPCIONAL string Alfanumérico, máx. 40 Campo personalizado 3
Custom_field4 OPCIONAL string Alfanumérico, máx. 40 Campo personalizado 4
Custom_field5 OPCIONAL string Alfanumérico, máx. 40 Campo personalizado 5

Endpoint: /api/acicloud/customers

Campo Tipo Descripción

f OPCIONAL array Filtros avanzados

🧪 Casos de Uso

1. Crear Cliente

curl -X POST "https://api.docucenter.com/api/acicloud/customer" \ -H "Authorization: Bearer YOUR_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "CustomerID": "CUST001", "Customer_Bill_Name": "Empresa Ejemplo S.A.", "Email": "contacto@empresa.com", "RUC": "1234567890123" }'

2. Obtener Clientes

curl -X GET "https://api.docucenter.com/api/acicloud/customers" \ -H "Authorization: Bearer YOUR_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "limit": 10, "order_column": "Customer_Bill_Name" }'

3. Buscar Clientes por Nombre

curl -X GET "https://api.docucenter.com/api/acicloud/customers" \ -H "Authorization: Bearer YOUR_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "limit": 50, "f": [ { "column": "Customer_Bill_Name", "operator": "like", "query_1": "Empresa" } ] }'

4. Obtener Clientes Importados

curl -X GET "https://api.docucenter.com/api/acicloud/customers_imp" \ -H "Authorization: Bearer YOUR_TOKEN"

⚠️ Códigos de Estado HTTP

Código Descripción Cuándo Ocurre
200 Operación exitosa Consulta realizada correctamente
201 Cliente creado exitosamente Creación exitosa con sincronización
400 Datos de request inválidos Formato de request incorrecto o CustomerID duplicado
401 No autorizado Token faltante o inválido
422 Error de validación Campos inválidos o faltantes
500 Error interno del servidor Error de sincronización con Sage

📝 Notas Técnicas

  • CustomerID único: Debe ser único en toda la organización
  • Campos personalizados: Custom_field3-5 son útiles para categorización
  • Validación RUC: Sigue el patrón panameño estándar (^[a-zA-Z0-9_-]*$)
  • Multi-tenant: Compatible con el sistema multi-tenant de DocuCenter
  • Sincronización automática: Los clientes se sincronizan con Sage ACICloud
  • Mapeo de campos: RUC → Custom_field1, DV → Custom_field2
  • Validación email: Los emails deben tener formato válido
  • Límites de texto: Customer_Bill_Name máximo 39 caracteres
  • Filtrado avanzado: Soporte para operadores like, equals, etc.
