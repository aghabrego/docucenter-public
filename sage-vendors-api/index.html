🏪 API Proveedores - Sage ACICloud

📋 Descripción

API para gestionar proveedores en Sage ACICloud con filtrado avanzado, paginación y sincronización automática con el sistema ERP.

🌐 Base URL

/api/acicloud/vendors
🔐 Autenticación requerida: Bearer Token (Sanctum)
🔒 Middleware: check.activate.organization

✨ Características Principales

  • ✅ Filtrado Avanzado: Soporte para múltiples filtros y operadores
  • ✅ Paginación: Resultados paginados automáticamente
  • ✅ Ordenamiento: Ordenar por cualquier campo
  • ✅ Multi-tenant: Respeta el contexto de organización activa
  • ✅ Sincronización: Integración automática con Sage ACICloud

📚 Endpoints Disponibles

GET Obtener Lista de Proveedores

Endpoint: /api/acicloud/vendors

Obtiene la lista de proveedores con filtrado avanzado y paginación.

Parámetros de Query (Opcionales)

Parámetro Tipo Descripción Ejemplo
page OPCIONAL integer Página a obtener 2
per_page OPCIONAL integer Registros por página (máx 100) 50
sort OPCIONAL string Campo para ordenar "name"
order OPCIONAL string Dirección del ordenamiento "asc" o "desc"
filter OPCIONAL object Filtros aplicados Ver sección de filtros

Sistema de Filtros Avanzados

Operadores disponibles:

equals not_equals contains starts_with ends_with greater_than less_than between in not_in is_null is_not_null

Ejemplo de Request

GET /api/acicloud/vendors?page=1&per_page=25&sort=name&order=asc

Ejemplo con Filtros

GET /api/acicloud/vendors?filter[name][operator]=contains&filter[name][value]=Distribuidora&filter[active][operator]=equals&filter[active][value]=1

POST Crear Proveedor

Endpoint: /api/acicloud/vendor

Crea un nuevo proveedor con sincronización automática a Sage ACICloud.

Campos de Request

Campo Tipo Validación Descripción
VendorID REQUERIDO string Único, máx. 20 chars ID único del proveedor
VendrName REQUERIDO string Máx. 39 characters Nombre del proveedor
PhoneNumber OPCIONAL string Máx. 20 characters Teléfono del proveedor
Email OPCIONAL string Email válido, único, máx. 64 Email del proveedor
AddressLine1 OPCIONAL string - Dirección línea 1
AddressLine2 OPCIONAL string - Dirección línea 2
City REQUERIDO string Requerido Ciudad
State REQUERIDO string Requerido, máx. 2 chars Estado/Provincia
Zip OPCIONAL string Máx. 12 characters Código postal
Country REQUERIDO string Requerido País
RUC OPCIONAL string Alfanumérico, máx. 40 RUC del proveedor
DV OPCIONAL string Alfanumérico, máx. 40 Dígito verificador
VendorType REQUERIDO string Requerido, alfanumérico, máx. 40 Tipo de proveedor
TaxpayerType REQUERIDO string Requerido, alfanumérico, máx. 40 Tipo de contribuyente
Custom_field5 REQUERIDO string Requerido, alfanumérico, máx. 40 Campo personalizado 5

🧪 Casos de Uso

1. Obtener Lista de Proveedores

curl -X GET "https://api.docucenter.com/api/acicloud/vendors?page=1&per_page=25" \ -H "Authorization: Bearer YOUR_TOKEN"

2. Buscar Proveedores por Nombre

curl -X GET "https://api.docucenter.com/api/acicloud/vendors?filter[Name][operator]=contains&filter[Name][value]=Distribuidora" \ -H "Authorization: Bearer YOUR_TOKEN"

3. Crear Proveedor

curl -X POST "https://api.docucenter.com/api/acicloud/vendor" \ -H "Authorization: Bearer YOUR_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "VendorID": "VENDOR001", "VendrName": "Distribuidora Nacional S.A.", "Email": "compras@distribuidora.com", "City": "Ciudad de Panamá", "State": "PA", "Country": "Panamá", "VendorType": "Regular", "TaxpayerType": "Contributor", "Custom_field5": "Activo" }'

4. Obtener Proveedores Importados

curl -X GET "https://api.docucenter.com/api/acicloud/vendors_imp" \ -H "Authorization: Bearer YOUR_TOKEN"

⚠️ Códigos de Estado HTTP

Código Descripción Cuándo Ocurre
200 Consulta exitosa Lista obtenida correctamente
201 Proveedor creado exitosamente Creación exitosa con sincronización
400 Datos de entrada inválidos Formato de request incorrecto
401 No autorizado Token faltante o inválido
409 Proveedor duplicado VendorID ya existe
422 Error de validación Campos inválidos o faltantes
500 Error interno del servidor Error de sincronización con Sage

📝 Notas Técnicas

  • Multi-tenant: Todos los endpoints respetan el contexto de organización
  • Sincronización: Los proveedores se sincronizan automáticamente con Sage
  • Validación RUC: Implementa validación específica para RUC panameño
  • Monedas: Soporte para USD y PAB
  • Estados: Los proveedores pueden estar activos o inactivos
  • Límites de Crédito: Control de límites de crédito por proveedor
  • Campos Personalizados: Uso de Custom_field1-5 para datos específicos
  • Validación Email: Los emails deben ser únicos en el sistema
  • Patrón RUC/DV: Solo letras, números, guiones y guiones bajos (^[a-zA-Z0-9_-]*$)
