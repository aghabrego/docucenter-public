💳 API Pagos y Créditos - Sage ACICloud

📋 Descripción

API completa para gestionar órdenes de venta, recibos de pago y notas de crédito en Sage ACICloud con integración automática al módulo de cuentas por cobrar.

🌐 Base URL

/api/acicloud/
🔐 Autenticación requerida: Bearer Token (Sanctum)
🔒 Middleware: check.activate.organization

💼 Módulos Principales

📄 Órdenes de Venta

Creación, consulta y seguimiento de órdenes de venta con control de envíos

💰 Recibos de Pago

Registro de pagos recibidos de clientes con múltiples métodos de pago

🔄 Notas de Crédito

Manejo de devoluciones y ajustes de crédito para clientes

📚 Endpoints Disponibles

Endpoint: /api/acicloud/sales_order_status/{salesOrderNumber}

Consulta el estado detallado de una orden de venta específica, incluyendo información de envíos y pagos.

Parámetros de URL

POST Crear Orden de Venta

Endpoint: /api/acicloud/sales_order

Crea una nueva orden de venta con líneas de detalle y sincronización automática.

Campos de Request (Header)

Campo Tipo Descripción
CustomerID REQUERIDO string ID del cliente
SONumber REQUERIDO string Número único de orden
SODate REQUERIDO date Fecha de la orden
RequiredDate OPCIONAL date Fecha requerida de entrega
Items REQUERIDO array Líneas de detalle de la orden

Campos de Request (Items)

Campo Tipo Descripción
ItemID REQUERIDO string ID del producto/servicio
Quantity REQUERIDO decimal Cantidad solicitada
UnitPrice REQUERIDO decimal Precio unitario
Description OPCIONAL string Descripción del item

Ejemplo de Request

{
  "CustomerID": "CUST001",
  "SONumber": "SO-2025-002",
  "SODate": "2025-01-29",
  "RequiredDate": "2025-02-05",
  "ShipToAddress": "Calle 50, Edificio Global Plaza",
  "ShipToCity": "Ciudad de Panamá",
  "Items": [
    {
      "ItemID": "PROD001",
      "Quantity": 5,
      "UnitPrice": 250.00,
      "Description": "Laptop Dell Inspiron 15"
    },
    {
      "ItemID": "PROD002", 
      "Quantity": 3,
      "UnitPrice": 150.00,
      "Description": "Mouse Inalámbrico"
    }
  ]
}

Respuesta Exitosa 201

{
  "success": true,
  "data": {
    "SONumber": "SO-2025-002",
    "CustomerID": "CUST001",
    "Status": "pending",
    "TotalAmount": 1700.00,
    "OrderDate": "2025-01-29",
    "sage_sync_status": "synced",
    "created_at": "2025-01-29T15:30:00.000000Z"
  }
}

GET Obtener Órdenes de Venta

Endpoint: /api/acicloud/sales_order

Obtiene la lista de órdenes de venta con filtrado y paginación.

Parámetros de Query (Opcionales)

Parámetro Tipo Descripción
status OPCIONAL string Filtrar por estado
customer_id OPCIONAL string Filtrar por cliente
page OPCIONAL integer Página de resultados
per_page OPCIONAL integer Registros por página

POST Crear Recibo de Cliente

Endpoint: /api/acicloud/customer_receipt_imp

Registra un pago recibido de un cliente con múltiples métodos de pago.

Métodos de Pago Válidos

cash check credit_card bank_transfer ach wire_transfer

Campos de Request

Campo Tipo Descripción
CustomerID REQUERIDO string ID del cliente
ReceiptNumber REQUERIDO string Número único del recibo
ReceiptDate REQUERIDO date Fecha del recibo
PaymentMethod REQUERIDO string Método de pago utilizado
Amount REQUERIDO decimal Monto del pago
Reference OPCIONAL string Número de referencia

Ejemplo de Request

{
  "CustomerID": "CUST001",
  "ReceiptNumber": "REC-2025-001",
  "ReceiptDate": "2025-01-29",
  "PaymentMethod": "bank_transfer",
  "Amount": 1500.00,
  "Reference": "TXN789123456",
  "Notes": "Pago parcial orden SO-2025-001"
}

Respuesta Exitosa 201

{
  "success": true,
  "data": {
    "ReceiptNumber": "REC-2025-001",
    "CustomerID": "CUST001",
    "Amount": 1500.00,
    "PaymentMethod": "bank_transfer",
    "Status": "processed",
    "sage_sync_status": "synced",
    "created_at": "2025-01-29T16:00:00.000000Z"
  }
}

POST Crear Nota de Crédito de Cliente

Endpoint: /api/acicloud/customer_credit_memo

Crea una nota de crédito para manejar devoluciones y ajustes de clientes.

Campos de Request

Campo Tipo Descripción
CustomerID REQUERIDO string ID del cliente
CreditMemoNumber REQUERIDO string Número único de la nota
CreditMemoDate REQUERIDO date Fecha de la nota de crédito
Amount REQUERIDO decimal Monto del crédito
Reason REQUERIDO string Motivo del crédito
OriginalInvoice OPCIONAL string Factura original relacionada

Ejemplo de Request

{
  "CustomerID": "CUST001",
  "CreditMemoNumber": "CM-2025-001",
  "CreditMemoDate": "2025-01-29",
  "Amount": 300.00,
  "Reason": "Producto defectuoso devuelto",
  "OriginalInvoice": "INV-2025-055",
  "Description": "Devolución laptop con falla en pantalla"
}

Respuesta Exitosa 201

{
  "success": true,
  "data": {
    "CreditMemoNumber": "CM-2025-001",
    "CustomerID": "CUST001",
    "Amount": 300.00,
    "Status": "approved",
    "sage_sync_status": "synced",
    "created_at": "2025-01-29T17:00:00.000000Z"
  }
}

🧪 Casos de Uso

1. Consultar Estado de Orden de Venta

curl -X GET "https://api.docucenter.com/api/acicloud/sales_order_status/SO-2025-001" \ -H "Authorization: Bearer YOUR_TOKEN"

2. Crear Orden de Venta

curl -X POST "https://api.docucenter.com/api/acicloud/sales_order" \ -H "Authorization: Bearer YOUR_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "CustomerID": "CUST001", "SONumber": "SO-2025-002", "SODate": "2025-01-29", "Items": [ { "ItemID": "PROD001", "Quantity": 5, "UnitPrice": 250.00 } ] }'

3. Registrar Pago

curl -X POST "https://api.docucenter.com/api/acicloud/customer_receipt_imp" \ -H "Authorization: Bearer YOUR_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "CustomerID": "CUST001", "ReceiptNumber": "REC-2025-001", "ReceiptDate": "2025-01-29", "PaymentMethod": "bank_transfer", "Amount": 1500.00 }'

4. Crear Nota de Crédito

curl -X POST "https://api.docucenter.com/api/acicloud/customer_credit_memo" \ -H "Authorization: Bearer YOUR_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "CustomerID": "CUST001", "CreditMemoNumber": "CM-2025-001", "CreditMemoDate": "2025-01-29", "Amount": 300.00, "Reason": "Producto defectuoso" }'

⚠️ Códigos de Estado HTTP

Código Descripción Cuándo Ocurre
200 Consulta exitosa Datos obtenidos correctamente
201 Recurso creado exitosamente Orden/pago/crédito creado con sincronización
400 Datos de request inválidos Formato incorrecto o datos duplicados
401 No autorizado Token faltante o inválido
422 Error de validación Campos inválidos o faltantes
500 Error interno del servidor Error de sincronización con Sage

📝 Notas Técnicas

  • Multi-tenant: Todos los endpoints respetan el contexto de organización
  • Sincronización automática: Integración completa con Sage ACICloud
  • Control de estados: Seguimiento completo del ciclo de vida de órdenes
  • Múltiples métodos de pago: Soporte para efectivo, transferencias, tarjetas
  • Gestión de créditos: Manejo completo de devoluciones y ajustes
  • Asientos contables: Generación automática de asientos en Sage
  • Validación de montos: Control de precisión decimal en cálculos
  • Números únicos: Validación de unicidad en números de documento
  • Tracking de envíos: Información detallada de envíos y entregas
  • Cuentas por cobrar: Actualización automática de balances de clientes
