API Facturación Electrónica - Integración Meypar

Crear Venta Meypar

Endpoint: POST /api/v1/fe/create_sale_meypar
Controller: FeController::createSaleMeypar
Request Class: CreateSaleMeyparRequest
Autenticación: Bearer Token requerido
Middleware: check.activate.organization

Descripción

Crea y emite una factura electrónica basada en datos provenientes del sistema Meypar (estacionamientos y servicios de parqueo en Colombia).

Estructura del Request

Campos Principales

Campo Tipo Requerido Descripción Límite
documento.tipo_documento string ✅ Tipo de documento -
documento.numero string ✅ Número del documento 20 caracteres
documento.fecha string ✅ Fecha del documento (YYYY-MM-DD) -

Emisor

Campo Tipo Requerido Descripción Límite

Campo Tipo Requerido Descripción Límite

Validaciones Colombianas

El sistema implementa validaciones automáticas para documentos de identificación colombianos:

🏢 NIT de Empresa

  • Formato: XXXXXXXXX-X (9 dígitos + guión + dígito verificador)
  • Ejemplo válido: 900123456-1
  • ReceiverType: Automáticamente asignado como 1 (Contribuyente)
  • Custom_field5: Se almacena el código de ubicación de la organización

👤 Cédula de Persona Natural

  • Formato: Solo números de 6 a 10 dígitos
  • Ejemplos válidos: 79123456, 1234567890
  • ReceiverType: Automáticamente asignado como 2 (Persona natural)
  • Custom_field5: Se almacena como null

🛒 Consumidor Final

  • Formatos válidos: 0-0-0, cadena vacía, o documento inválido (auto-corrección)
  • ReceiverType: Automáticamente asignado como 2 (Consumidor final)
  • Custom_field5: Se almacena como null

Casos de Uso

  • Estacionamientos: Cobro por tiempo de estancia
  • Recarga Eléctrica: Servicios de recarga para vehículos eléctricos
  • Servicios Adicionales: Lavado, mantenimiento, etc.
  • Multi-terminal: Soporte para múltiples terminales por ubicación

Códigos de Respuesta

Código Descripción
201 Factura procesada exitosamente
400 Datos de entrada inválidos
401 No autorizado
422 Error de validación
500 Error interno del servidor

Notas Técnicas

  • Procesamiento: Asíncrono usando CreateSaleMeyparJob
  • Multi-tenant: Respeta contexto de organización activa
  • Moneda: Manejo específico de Pesos Colombianos (COP)
  • Ubicación: Integración con ubicaciones colombianas
  • Validación automática: Documentos colombianos (NIT, Cédula)
  • Medios de pago múltiples: Soporte para efectivo, tarjeta, cheque, transferencia
