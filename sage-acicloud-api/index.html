🏢 API Sage ACICloud - Documentación Técnica

📋 Descripción General

La API Sage ACICloud proporciona integración completa con el sistema Sage 50cloud, permitiendo la sincronización bidireccional de datos contables y de facturación entre DocuCenter y Sage.

🔐 Autenticación

Todas las rutas requieren autenticación Sanctum y verificación de organización activa:

Authorization: Bearer {token}
Content-Type: application/json
X-Organization-ID: {organization_id}

🌐 URL Base

https://apconpanama.me/api/acicloud/

📋 Módulo de Facturas

GET /invoices

Obtiene el listado de facturas desde Sage.

Respuesta:

{
  "success": true,
  "data": [
    {
      "invoice_number": "INV-001",
      "customer_code": "CUST001",
      "total": 1000.00,
      "date": "2025-08-12",
      "status": "posted"
    }
  ]
}

👥 Módulo de Clientes

GET /customers

Lista todos los clientes de Sage.

Parámetros de consulta:

  • page: Página (default: 1)
  • limit: Registros por página (default: 50)
  • search: Búsqueda por nombre o código

POST /customer

Importa un cliente desde DocuCenter a Sage.

Request Body:

{
  "customer_code": "CUST001",
  "name": "Cliente Ejemplo S.A.",
  "ruc": "1234567890-1-2024",
  "email": "cliente@ejemplo.com",
  "phone": "+507-1234-5678",
  "address": {
    "street": "Calle Principal",
    "city": "Ciudad de Panamá",
    "province": "Panamá",
    "postal_code": "0000"
  },
  "credit_limit": 5000.00,
  "payment_terms": "Net 30"
}

GET /customers_imp

Obtiene el listado de clientes importados desde DocuCenter.

💰 Módulo de Contabilidad

GET /accounts

Obtiene el catálogo de cuentas contables de Sage.

POST /journal_entry

Registra un asiento contable en Sage.

Request Body:

{
  "date": "2025-08-12",
  "reference": "JE-001",
  "description": "Asiento de ejemplo",
  "entries": [
    {
      "account_code": "1100",
      "debit": 1000.00,
      "credit": 0.00,
      "description": "Cuenta por cobrar"
    },
    {
      "account_code": "4100",
      "debit": 0.00,
      "credit": 1000.00,
      "description": "Ingresos por servicios"
    }
  ]
}

🔄 Sincronización

La integración permite sincronización bidireccional:

  • DocuCenter → Sage: Clientes, proveedores, productos, facturas
  • Sage → DocuCenter: Estados de cuenta, balances, reportes contables

⚠️ Consideraciones Importantes

  1. Códigos únicos: Asegurar que los códigos de cliente/proveedor/producto sean únicos
  2. Formato RUC: Validar formato de RUC según normativas panameñas
  3. Límites de crédito: Configurar límites apropiados según políticas empresariales
  4. Términos de pago: Usar términos estándar de Sage (Net 15, Net 30, etc.)
