📍 API de Ubicaciones - DocuCenter

📋 Descripción General

La API de Ubicaciones permite gestionar direcciones, provincias, distritos y corregimientos de Panamá para validación fiscal y operaciones de entrega en el sistema DocuCenter.

Autenticación: Bearer Token requerido para todos los endpoints

Multi-tenant: Requiere header X-Organization-ID

🌍 Obtener Provincias

Obtiene la lista completa de provincias de Panamá.

Controller: Api\V1\LocationController::provinces

X-Organization-ID: {organization_id}

📍 Validar Dirección Completa

POST /api/v1/locations/validate-address

Valida una dirección completa con provincia, distrito y corregimiento.

Controller: Api\V1\LocationController::validateAddress

📝 Campos de Request

Campo Tipo Requerido Descripción Ejemplo
province_id integer ✅ ID de la provincia 8
district_id integer ✅ ID del distrito 1
corregimiento_id integer ✅ ID del corregimiento 11
street_address string ✅ Dirección de calle "Calle 50 #123"
postal_code string ❌ Código postal "0801"

📤 Ejemplo de Request

{
  "province_id": 8,
  "district_id": 1,
  "corregimiento_id": 11,
  "street_address": "Calle 50, Edificio Plaza 2000",
  "postal_code": "0801"
}

🗺️ Integración con RUC

Validación de Ubicación para RUC

Las ubicaciones se utilizan para validar RUCs según la provincia:

  • RUC Natural: {provincia}-{tomo}-{folio}
  • RUC Jurídico: {registro}-{provincia}-{año}
  • Extranjero: PE-{secuencial}

Ejemplos de Validación:

{
  "ruc": "8-123-456",
  "validation": {
    "province_code": "8",
    "province_name": "Panamá",
    "type": "natural_person"
  }
}

{
  "ruc": "155757563-8-2024",
  "validation": {
    "province_code": "8", 
    "province_name": "Panamá",
    "type": "juridical_person"
  }
}

⚠️ Códigos de Error Comunes

Código Mensaje Descripción
404 Province not found ID de provincia inválido
404 District not found ID de distrito inválido
422 Invalid hierarchy Distrito no pertenece a la provincia
422 Invalid corregimiento Corregimiento no pertenece al distrito

💡 Casos de Uso

1. Formulario de Registro de Cliente

// 1. Cargar provincias
const provinces = await fetch('/api/v1/locations/provinces');

// 2. Usuario selecciona provincia
const selectedProvince = 8; // Panamá

// 3. Cargar distritos de la provincia
const districts = await fetch(`/api/v1/locations/provinces/${selectedProvince}/districts`);

// 4. Usuario selecciona distrito
const selectedDistrict = 1; // Panamá

// 5. Cargar corregimientos del distrito
const corregimientos = await fetch(`/api/v1/locations/districts/${selectedDistrict}/corregimientos`);

2. Validación de RUC con Ubicación

// Extraer provincia del RUC
const ruc = "8-123-456";
const provinceCode = ruc.split('-')[0];

// Validar que la provincia existe
const province = await fetch(`/api/v1/locations/search?q=${provinceCode}&type=province`);
