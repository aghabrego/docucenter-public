# API Sage ACICloud

Documentación completa de las APIs de integración con Sage ACICloud para la gestión contable y administrativa.

## Módulos Disponibles

### Ventas y Facturación

- [**Facturación - Invoices**](invoices-api.md) - Gestión de facturas y ventas
- [**Órdenes de Venta**](sales-orders-api.md) - Creación y gestión de órdenes de venta

### Gestión de Contactos

- [**Clientes - Customers**](customers-api.md) - Administración de clientes
- [**Proveedores - Vendors**](vendors-api.md) - Gestión de proveedores

### Inventario y Productos

- [**Productos - Products**](products-api.md) - Catálogo de productos y servicios
- [**Inventario - Inventory**](inventory-api.md) - Control de inventario y existencias

### Compras y Pagos

- [**Compras - Purchases**](purchases-api.md) - Registro de compras y gastos
- [**Pagos y Créditos**](payments-api.md) - Gestión de pagos y créditos

### Contabilidad

- [**Contabilidad General**](accounting-api.md) - APIs de contabilidad general
- [**Trabajos - Jobs**](jobs-api.md) - Gestión de proyectos y trabajos

## Características de la Integración

- Sincronización bidireccional de datos
- Validaciones automáticas
- Manejo de errores y reintentos
- Soporte para múltiples organizaciones
- Autenticación segura con tokens
