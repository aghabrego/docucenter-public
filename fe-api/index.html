🧾 API Facturación Electrónica (FE) - Documentación Técnica

📋 Descripción General

La API de Facturación Electrónica (FE) proporciona endpoints especializados para la emisión, importación y gestión de documentos fiscales electrónicos conforme a las regulaciones de la DGI de Panamá.

🔐 Autenticación

Todas las rutas requieren autenticación Sanctum y verificación de organización activa:

Authorization: Bearer {token}
Content-Type: application/json
X-Organization-ID: {organization_id}

🌐 URL Base

https://apconpanama.me/api/v1/fe/

📄 Módulo de Documentos Fiscales

GET /download_base64_document/{id}

Descarga un documento fiscal en formato base64.

Parámetros:

  • id: ID único del documento fiscal

Respuesta:

{
  "success": true,
  "data": {
    "document_id": "FE-2025-001234",
    "base64_content": "JVBERi0xLjQKMSAwIG9iago8PAovVHlwZSAvQ2F0YWxvZ...",
    "mime_type": "application/pdf",
    "filename": "factura_001234.pdf"
  }
}

POST /import_xml

Importa un documento XML de facturación electrónica.

Request Body:

{
  "xml_content": "...",
  "document_type": "01", // 01=Factura, 02=Nota Crédito, 03=Nota Débito
  "validate_dgi": true
}

Respuesta:

{
  "success": true,
  "data": {
    "document_id": "FE-2025-001234",
    "dgi_number": "01234567890123456789",
    "status": "imported",
    "validation_errors": []
  }
}

POST /emit_json_object

Emite un documento fiscal a partir de un objeto JSON.

Request Body:

{
  "document_type": "01",
  "emission_point": "001",
  "customer": {
    "identification_type": "04", // RUC
    "identification": "1234567890-1-2024",
    "name": "Cliente Ejemplo S.A.",
    "email": "cliente@ejemplo.com"
  },
  "items": [
    {
      "description": "Servicio de Consultoría",
      "quantity": 1,
      "unit_price": 1000.00,
      "tax_rate": 0.07
    }
  ],
  "totals": {
    "subtotal": 1000.00,
    "tax": 70.00,
    "total": 1070.00
  }
}

🏷️ Tipos de Documento

  • 01 = Factura Comercial
  • 02 = Nota de Crédito
  • 03 = Nota de Débito
  • 04 = Nota de Entrega
  • 05 = Documento de Soporte

🆔 Tipos de Identificación

  • 04 = RUC (Registro Único de Contribuyente)
  • 02 = Cédula de Identidad Personal
  • 03 = Pasaporte
  • 06 = Otro

⚠️ Consideraciones Importantes

  1. Cumplimiento DGI: Todos los documentos deben cumplir con las normativas de la Dirección General de Ingresos de Panamá
  2. Validación previa: Recomendamos validar los datos antes de enviarlos para emisión
  3. Formatos de fecha: Usar formato ISO 8601 (YYYY-MM-DD)
  4. Decimales: Máximo 2 decimales para montos
  5. Encoding: UTF-8 para todos los textos
