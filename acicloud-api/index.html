☁️ API ACICloud - Documentación

📋 Descripción General

La API ACICloud proporciona acceso programático a los servicios de facturación electrónica y gestión empresarial de APC Panamá. Esta API REST permite integrar funcionalidades de DocuCenter en aplicaciones externas.

🌐 URL Base

https://apconpanama.me/api/acicloud

🔐 Autenticación

La API utiliza autenticación mediante token Bearer. Incluye el token en el header de autorización:

Authorization: Bearer {tu_token_de_acceso}
Content-Type: application/json
Accept: application/json

🚀 Endpoints Principales

1. Información del Sistema

GET /api/acicloud

Obtiene información general de la API y estado del sistema.

Respuesta:

{
  "success": true,
  "data": {
    "api_version": "v1.0",
    "system_status": "operational",
    "services": [
      "electronic_invoicing",
      "sage_integration",
      "document_management"
    ]
  }
}

2. Gestión de Organizaciones

GET /organizations

Lista las organizaciones disponibles para el usuario autenticado.

POST /organizations

Crear nueva organización.

Request Body:

{
  "name": "Mi Empresa S.A.",
  "ruc": "1234567890-1-2024",
  "email": "contacto@miempresa.com",
  "address": "Calle Principal, Ciudad de Panamá"
}

3. Facturación Electrónica

POST /invoices

Crear nueva factura electrónica.

Request Body:

{
  "customer": {
    "name": "Cliente Ejemplo",
    "ruc": "9876543210-1-2024",
    "email": "cliente@ejemplo.com"
  },
  "items": [
    {
      "description": "Servicio de Consultoría",
      "quantity": 1,
      "unit_price": 500.00
    }
  ]
}

4. Gestión de Clientes

GET /customers

Lista todos los clientes de la organización.

POST /customers

Crear nuevo cliente.

PUT /customers/{id}

Actualizar información de cliente existente.

5. Productos y Servicios

GET /products

Lista todos los productos y servicios.

POST /products

Crear nuevo producto o servicio.

📊 Códigos de Respuesta

  • 200 - Operación exitosa
  • 201 - Recurso creado exitosamente
  • 400 - Error en los datos enviados
  • 401 - No autorizado - Token inválido
  • 403 - Prohibido - Sin permisos suficientes
  • 404 - Recurso no encontrado
  • 422 - Error de validación
  • 500 - Error interno del servidor

📝 Formato de Respuestas

Todas las respuestas siguen un formato estándar:

{
  "success": true|false,
  "data": {...},
  "message": "Mensaje descriptivo",
  "errors": {...} // Solo en caso de error
}

🔄 Rate Limiting

La API tiene límites de velocidad para prevenir abuso:

  • General: 1000 requests por hora
  • Facturación: 500 requests por hora
  • Autenticación: 10 requests por minuto

🌐 Webhooks

ACICloud puede enviar notificaciones webhook para eventos importantes:

  • invoice.created - Nueva factura creada
  • invoice.paid - Factura pagada
  • customer.updated - Cliente actualizado

📚 SDKs Disponibles

  • PHP: Composer package disponible
  • JavaScript: NPM package
  • Python: PyPI package

⚠️ Consideraciones de Seguridad

  1. HTTPS Obligatorio: Todas las comunicaciones deben usar HTTPS
  2. Tokens seguros: Nunca expongas tokens en código del lado cliente
  3. Validación: Always validate input data
  4. Logs: Monitorea logs para detectar uso anómalo
