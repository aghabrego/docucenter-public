🧾 API Facturas - Sage ACICloud

📋 Obtener Facturas

Endpoint: GET /api/acicloud/invoices
Request Class: ACIcloudRequest
Autenticación: Bearer Token requerido

✨ Características del Endpoint

  • ✅ Filtrado Avanzado: Sistema de filtros con múltiples operadores
  • ✅ Ordenamiento Flexible: Ordenar por cualquier columna disponible
  • ✅ Paginación Automática: Resultados paginados con navegación
  • ✅ Detalles Completos: Incluye líneas de detalle de cada factura
  • ✅ Multi-tenant: Compatible con conexiones multi-tenant

📝 Parámetros de Consulta

Campo Tipo Requerido Descripción Ejemplo
order_column string ❌ Columna para ordenamiento "Date"
order_direction string ❌ Dirección del ordenamiento "desc"
limit integer ❌ Límite de registros (mín: 1) 50
filter_match string ❌ Lógica de filtros "and" o "or"
f array ❌ Array de filtros avanzados []

📊 Columnas Disponibles para Filtrado

Campo Descripción Tipo Ejemplo
TransactionID ID de transacción string "INV001"
SalesInvoiceNumber Número de factura de venta string "FAC-2025-0001"
CustomerID ID del cliente string "CUST001"
CustomerName Nombre del cliente string "ABC Corporation S.A."
Date Fecha de la factura date "2025-01-29"
ShipDate Fecha de envío date "2025-01-30"
Total Total de la factura decimal 2621.50
TaxID ID del impuesto string "TAX001"

📈 Columnas Ordenables

  • TransactionID
  • SalesInvoiceNumber
  • Total
  • Date
  • ShipDate

🔍 Sistema de Filtros Avanzado

⚙️ Operadores Disponibles

Operador Descripción Requiere query_2 Ejemplo
eq Igual a ❌ Total = 1000.00
ne No igual a ❌ Status ≠ "cancelled"
gt Mayor que ❌ Total > 500.00
gte Mayor o igual que ❌ Total ≥ 100.00
lt Menor que ❌ Total < 1000.00
lte Menor o igual que ❌ Total ≤ 5000.00
like Contiene ❌ CustomerName contiene "ABC"
not_like No contiene ❌ CustomerName no contiene "TEST"
between Entre ✅ Date entre "2025-01-01" y "2025-12-31"
not_between No entre ✅ Total no entre 100 y 500
in En lista ❌ CustomerID en ["CUST001", "CUST002"]
not_in No en lista ❌ Status no en ["cancelled", "void"]

📋 Estructura de Filtros

{
  "column": "string",     // REQUERIDO - Una de las columnas disponibles
  "operator": "string",   // REQUERIDO - Uno de los operadores válidos
  "query_1": "string",    // REQUERIDO - Valor a filtrar
  "query_2": "string"     // OPCIONAL - Solo requerido para between y not_between
}

📤 Ejemplos de Consultas

🔸 Consulta Básica

{
  "order_column": "Date",
  "order_direction": "desc",
  "limit": 100
}

🔸 Consulta con Filtros Múltiples

{
  "order_column": "Date",
  "order_direction": "desc",
  "limit": 100,
  "filter_match": "and",
  "f": [
    {
      "column": "Date",
      "operator": "between",
      "query_1": "2025-01-01",
      "query_2": "2025-12-31"
    },
    {
      "column": "Total",
      "operator": "gte",
      "query_1": "100.00"
    },
    {
      "column": "CustomerName",
      "operator": "like",
      "query_1": "Corporation"
    }
  ]
}

🔸 Consulta por Rango de Fechas

{
  "f": [
    {
      "column": "Date",
      "operator": "between",
      "query_1": "2025-08-01",
      "query_2": "2025-08-31"
    }
  ]
}

🔸 Consulta por Clientes Específicos

{
  "f": [
    {
      "column": "CustomerID",
      "operator": "in",
      "query_1": "CUST001,CUST002,CUST003"
    }
  ]
}

🔧 Ejemplos de cURL

Consulta Básica

curl -X GET "https://api.docucenter.com/api/acicloud/invoices" \
     -H "Authorization: Bearer YOUR_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{
       "limit": 10,
       "order_column": "Date",
       "order_direction": "desc"
     }'

⚙️ Notas Técnicas

  • DataViewer Trait: Utiliza el trait DataViewer para filtrado avanzado
  • Paginación Automática: Soporta paginación automática con navegación
  • Caché de Consultas: Implementa caché de consultas para mejor rendimiento
  • Multi-tenant: Compatible con conexiones multi-tenant de DocuCenter
  • Detalles Incluidos: Cada factura incluye automáticamente sus líneas de detalle
  • Validación de Columnas: Valida que las columnas de ordenamiento y filtrado sean válidas

🔗 Integración con Sage ACICloud

Las facturas se obtienen directamente desde Sage ACICloud, manteniendo sincronización en tiempo real y proporcionando datos consistentes y actualizados.
