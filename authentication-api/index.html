🔐 API de Autenticación - DocuCenter

📋 Descripción General

La API de Autenticación permite obtener tokens de acceso para interactuar con todas las APIs de DocuCenter. Utiliza autenticación basada en tokens Bearer con Sanctum.

🚪 Generar Token de Acceso

POST /api/auth/login

Genera un token de acceso utilizando credenciales de usuario.

Controller: Auth\LoginController::login

Middleware: Ninguno (endpoint público)

📝 Campos de Request

Campo Tipo Requerido Descripción Ejemplo
login string ✅ Username o email del usuario "user@empresa.com"
password string ✅ Contraseña del usuario "mi_password_segura"
remember boolean ❌ Recordar sesión (opcional) true
device_name string ❌ Nombre del dispositivo/aplicación "Mi App Web"

✅ Validaciones

  • login: Email válido o username (mínimo 3 caracteres)
  • password: Mínimo 6 caracteres
  • device_name: Máximo 100 caracteres (opcional)

📤 Ejemplo de Request

{
  "login": "admin@docucenter.com",
  "password": "password123",
  "device_name": "DocuCenter Web App",
  "remember": true
}

📥 Respuesta de Éxito

{
  "success": true,
  "message": "Autenticación exitosa",
  "data": {
    "access_token": "1|eyJ0eXAiOiJKV1QiLCJhbGciOiJSUzI1NiJ9...",
    "token_type": "Bearer",
    "expires_in": 86400,
    "expires_at": "2025-08-13 21:29:09",
    "user": {
      "id": 1,
      "name": "Administrador",
      "email": "admin@docucenter.com",
      "username": "admin",
      "created_at": "2025-01-15T08:00:00Z"
    }
  }
}

❌ Respuesta de Error

{
  "success": false,
  "message": "Credenciales inválidas",
  "errors": {
    "login": ["Las credenciales proporcionadas son incorrectas."]
  }
}

👤 Obtener Información del Usuario

GET /api/auth/user

Obtiene información del usuario autenticado.

Autenticación: Bearer Token requerido

📤 Headers Requeridos

Authorization: Bearer {token}
Content-Type: application/json

📥 Respuesta de Éxito

{
  "success": true,
  "data": {
    "id": 1,
    "name": "Administrador",
    "email": "admin@docucenter.com",
    "username": "admin",
    "email_verified_at": "2025-01-15T08:30:00Z",
    "created_at": "2025-01-15T08:00:00Z",
    "updated_at": "2025-08-12T10:15:00Z",

      {
        "id": 1,
        "name": "Empresa Principal S.A.",
        "ruc": "1234567890123",
        "status": "active"
      }
    ]
  }
}

🚪 Cerrar Sesión

POST /api/auth/logout

Revoca el token de acceso actual y cierra la sesión.

Autenticación: Bearer Token requerido

📤 Headers Requeridos

Authorization: Bearer {token}
Content-Type: application/json

📥 Respuesta de Éxito

{
  "success": true,
  "message": "Sesión cerrada exitosamente"
}

🔑 Uso del Token

📋 Formato del Header de Autorización

Una vez obtenido el token, debe incluirse en todas las requests a las APIs:

Authorization: Bearer {access_token}
Content-Type: application/json
X-Organization-ID: {organization_id}

⏰ Expiración del Token

  • Duración por defecto: 24 horas (86400 segundos)
  • Campo expires_at: Indica la fecha y hora exacta de expiración
  • Renovación: Debe obtener un nuevo token antes de la expiración

🏢 Multi-Tenant

DocuCenter es multi-tenant. Después de autenticarse, debe:

  1. Obtener la lista de organizaciones con GET /api/v1/organizations
  2. Incluir el header X-Organization-ID en todas las requests subsecuentes

⚠️ Códigos de Error Comunes

Código Descripción Solución
401 Token inválido o expirado Obtener nuevo token con /api/auth/login
422 Datos de validación incorrectos Revisar campos requeridos y formatos
429 Demasiados intentos de login Esperar antes de intentar nuevamente

🛡️ Consideraciones de Seguridad

  1. HTTPS Obligatorio: Todas las comunicaciones deben usar HTTPS
  2. Almacenamiento Seguro: Guarda los tokens de forma segura
  3. Rotación de Tokens: Implementa renovación automática antes de expiración
  4. Rate Limiting: Respeta los límites de intentos de login
  5. Logout: Siempre revoca tokens al cerrar sesión

💡 Ejemplos de Implementación

JavaScript/Axios

// Login
const loginResponse = await axios.post('/api/auth/login', {
  login: 'user@empresa.com',
  password: 'password123',
  device_name: 'Mi App Web'
});

const token = loginResponse.data.data.access_token;

// Usar token en requests subsecuentes
axios.defaults.headers.common['Authorization'] = `Bearer ${token}`;

// Obtener organizaciones
const orgsResponse = await axios.get('/api/v1/organizations');

// Configurar organización
axios.defaults.headers.common['X-Organization-ID'] = orgsResponse.data.data.organizations[0].id;

PHP/cURL

<?php
// Login
$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, 'https://apconpanama.me/api/auth/login');
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
    'login' => 'user@empresa.com',
    'password' => 'password123',
    'device_name' => 'Mi App PHP'
]));
curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);

$response = curl_exec($ch);
$data = json_decode($response, true);
$token = $data['data']['access_token'];

// Usar token en requests subsecuentes
$headers = [
    'Authorization: Bearer ' . $token,
    'Content-Type: application/json'
];
?>
