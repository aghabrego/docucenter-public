🏢 API de Organizaciones - DocuCenter

📋 Descripción General

La API de Organizaciones permite gestionar entidades fiscales multi-tenant en DocuCenter. Cada organización representa una empresa independiente con su propio RUC, configuración fiscal y datos de facturación electrónica.

Autenticación: Bearer Token requerido para todos los endpoints

🔍 Obtener Organizaciones del Usuario

GET /api/v1/organizations

Obtiene todas las organizaciones a las que tiene acceso el usuario autenticado.

Controller: Api\V1\OrganizationController::index

Autenticación: Bearer Token requerido

📤 Headers Requeridos

➕ Crear Nueva Organización

POST /api/v1/organizations

Crea una nueva organización fiscal.

Controller: Api\V1\OrganizationController::store

Permisos: Solo usuarios con rol de administrador pueden crear organizaciones

📝 Campos de Request

Campo Tipo Requerido Descripción Ejemplo
name string ✅ Nombre de la organización "Mi Empresa S.A."
ruc string ✅ RUC de la empresa (formato Panamá) "1234567890123"
dv string ✅ Dígito verificador del RUC "2024"
email string ✅ Email de contacto "info@miempresa.com"
phone string ❌ Teléfono de contacto "+507 123-4567"
address string ✅ Dirección fiscal "Av. Balboa, Ciudad de Panamá"
website string ❌ Sitio web "https://miempresa.com"
business_type string ✅ Tipo de negocio "company"
pac_provider string ✅ Proveedor PAC "thefactoryhka"

✅ Validaciones

  • name: Máximo 255 caracteres
  • ruc: Formato válido RUC Panamá (13 dígitos)
  • dv: Formato válido dígito verificador
  • email: Email válido, único en el sistema
  • business_type: Valores: "company", "branch", "individual"
  • pac_provider: Valores: "thefactoryhka", "alanube"

📤 Ejemplo de Request

{
  "name": "Mi Nueva Empresa S.A.",
  "ruc": "9876543210987",
  "dv": "2024",
  "email": "contabilidad@nuevaempresa.com",
  "phone": "+507 987-6543",
  "address": "Centro Comercial, San Miguelito",
  "website": "https://nuevaempresa.com",
  "business_type": "company",
  "pac_provider": "thefactoryhka"
}

✏️ Actualizar Organización

PUT /api/v1/organizations/{id}

Actualiza los datos de una organización existente.

Controller: Api\V1\OrganizationController::update

Permisos: Solo usuarios con permisos de administración de la organización

📝 Campos de Request (todos opcionales)

Mismos campos que en creación, todos opcionales. Solo se actualizan los campos enviados.

📤 Ejemplo de Request

{

  "phone": "+507 111-2222",

🔧 Configurar PAC (Proveedor Autorizado de Certificación)

PUT /api/v1/organizations/{id}/pac-configuration

Configura el proveedor PAC para facturación electrónica.

Controller: Api\V1\OrganizationController::configurePac

📝 Campos de Request

Campo Tipo Requerido Descripción Ejemplo
pac_provider string ✅ Proveedor PAC "thefactoryhka"
environment string ✅ Ambiente de trabajo "production"
certificate_file file ✅ Archivo de certificado Base64 encoded
certificate_password string ✅ Password del certificado "mi_password"

📤 Ejemplo de Request

{
  "pac_provider": "thefactoryhka",
  "environment": "production",
  "certificate_file": "data:application/x-pkcs12;base64,MIIGXQIBAzCCBh...",
  "certificate_password": "mi_password_certificado"
}

⚠️ Estados de Organización

Estado Descripción Facturación Electrónica
pending_verification Pendiente de verificación ❌ Deshabilitada
active Activa y operativa ✅ Habilitada
suspended Suspendida temporalmente ❌ Deshabilitada
inactive Inactiva ❌ Deshabilitada

🛡️ Validación RUC Panamá

DocuCenter incluye validación completa de RUC panameño:

Formatos Soportados:

  • Persona Natural: 8-123-456
  • Persona Jurídica: 155757563-2-2024
  • Extranjero: E-8-123456
  • Consumidor Final: 0-0-0

Provincias Soportadas:

1-Bocas del Toro, 2-Coclé, 3-Colón, 4-Chiriquí, 5-Darién, 6-Herrera, 7-Los Santos, 8-Panamá, 9-Veraguas, 10-Kuna Yala, 11-Emberá, 12-Ngäbe-Buglé, 13-Panamá Oeste, PE-Extranjero
