Análisis del Sistema Multi-Branch

Arquitectura de Organizaciones y Sucursales en DocuCenter

Última actualización: 3 de diciembre de 2025

Resumen Ejecutivo

Este documento analiza la arquitectura multi-tenant de DocuCenter con enfoque en el sistema de organizaciones, sucursales y el filtrado de datos por ID_compania.

⚠️ Problema Crítico Identificado: 36+ modelos sin filtrado automático por ID_compania, lo que permite acceso no autorizado a datos de otras sucursales.

class Companysession extends Model
{
    protected $table = 'CompanySession';
    
    protected $fillable = [
        'ID_compania',      // 100
        'CompanyNameSage50' // "Restaurante XYZ - Centro"
    ];
    
    /**
     * ⭐ SIEMPRE usa la base de datos principal
     */
    public function __construct(array $attributes = [])
    {
        parent::__construct($attributes);
        
        // Forzar conexión a BD principal (mysql)
        $this->setDefaultConnection();
    }
    
    public function organizations()
    {
        // UNA sucursal = UNA organización
        return $this->hasMany(Organization::class, 
                              'id_empresa', 
                              'ID_compania');
    }
}

⚠️ Aclaraciones Importantes:

  1. hasMany NO significa "muchas organizaciones por sucursal" - es convención de Eloquent
  2. En la práctica: 1 Sucursal = 1 Organización
  3. Modelo Companysession lee de BD Principal (usando setDefaultConnection())
  4. CompanySession en BD de Organización es copia local para importación/exportación

Problema Identificado

🚨 Escenario Problemático

Usuario: Juan
Organizaciones asignadas:
  - Org 1 (Restaurante Centro) → BD: rest_centro   → ID_compania: 100
  - Org 2 (Restaurante Norte)  → BD: rest_norte    → ID_compania: 200
  - Org 3 (Restaurante Sur)    → BD: rest_sur      → ID_compania: 300

Problema:
  Al consultar Sales_Header_Imp en rest_centro
  Juan ve TODAS las ventas, sin importar ID_compania
  
Debería ver solo:
  Ventas donde ID_compania = 100 (sucursal actual)

Flujo Incorrecto Actual

1. Usuario tiene 3 organizaciones
   └─> getCompanyIds() retorna [100, 200, 300]

2. Usuario cambia a BD de Org 1 (rest_centro)
   └─> DB::useDatabase('rest_centro')

3. Query: WHERE ID_compania IN (100, 200, 300)
   └─> ❌ ERROR: IDs 200 y 300 NO existen en rest_centro
   └─> Solo existe ID_compania = 100 en esta BD

Flujo Correcto Propuesto

1. Usuario tiene 3 organizaciones
   └─> Organization::find(25) // Org actual

2. Obtener ID_compania de la organización actual
   └─> Organization->id_empresa = 100

3. Usuario cambia a BD de Org 1
   └─> DB::useDatabase('rest_centro')

4. Query: WHERE ID_compania = 100
   └─> ✅ CORRECTO: Solo datos de esa sucursal

⭐ Solución Recomendada

Concepto Central

  • NO necesitamos tabla intermedia usuario-sucursal
  • 1 Organización = 1 Sucursal (CompanySession.ID_compania)
  • Filtrar por el ID_compania de la organización actual del usuario

1️⃣ Modificar OrganizationService

// app/Services/OrganizationService.php

/**
 * Obtiene el ID_compania de la organización actual
 * Una organización = una sucursal
 * 
 * @return int|null
 */
public function getCurrentCompanyId(): ?int
{
    $organization = $this->getOrganization();
    
    if (!$organization) {
        return null;
    }
    
    // Retornar id_empresa que es el ID_compania de CompanySession
    return $organization->id_empresa;
}

/**
 * Obtiene todos los ID_compania de las organizaciones del usuario
 * Útil para reportes consolidados
 * 
 * @return array
 */
public function getAllCompanyIds(): array
{
    $this->setDefaultConnection();
    $user = auth()->user();
    
    if (!$user) {
        return [];
    }
    
    return $user->organizations()
        ->pluck('id_empresa')
        ->filter()
        ->unique()
        ->values()
        ->toArray();
}

2️⃣ Crear Global Scope Reutilizable

// app/Models/Scopes/CompanyIdFilterScope.php

namespace App\Models\Scopes;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Scope;

class CompanyIdFilterScope implements Scope
{
    /**
     * Filtra automáticamente por ID_compania de la organización actual
     * Solo aplica cuando hay usuario autenticado
     */
    public function apply(Builder $builder, Model $model)
    {
        // Solo aplicar si hay usuario autenticado
        if (!auth()->check()) {
            return;
        }
        
        // Obtener ID_compania de la organización actual
        $organizationService = app(\App\Contracts\OrganizationServiceContract::class);
        $companyId = $organizationService->getCurrentCompanyId();
        
        if ($companyId) {
            $builder->where('ID_compania', $companyId);
        }
    }
}

3️⃣ Aplicar Scope a Modelos

// app/Models/SalesHeaderImp.php

namespace App\Models;

use App\Models\Scopes\CompanyIdFilterScope;
use Illuminate\Database\Eloquent\Model;

class SalesHeaderImp extends Model
{
    protected $table = 'Sales_Header_Imp';
    
    protected $fillable = [
        'ID_compania',
        'InvoiceNumber',
        'CustomerID',
        // ... otros campos
    ];
    
    /**
     * Bootstrap del modelo
     */
    protected static function booted()
    {
        // Aplicar filtrado automático por ID_compania
        static::addGlobalScope(new CompanyIdFilterScope);
    }
}

// O crear método en el modelo
class SalesHeaderImp extends Model
{
    public function scopeAllBranches(Builder $query)
    {
        return $query->withoutGlobalScope(CompanyIdFilterScope::class);

}

// Uso:
