Análisis del Sistema Multi-Sucursal con ID_compania

Arquitectura Multi-Tenant: Organizaciones y Sucursales

Versión 1.0 - 3 de diciembre de 2025

Contexto General

DocuCenter maneja un sistema multi-tenant donde:

  • Una Empresa/Matriz (CompanySession) puede tener múltiples Organizaciones
  • Cada Organización tiene su propia base de datos
  • Dentro de cada base de datos, existen múltiples Sucursales identificadas por ID_compania
  • Una organización puede gestionar múltiples sucursales de la misma empresa

Caso de Uso Real:

Empresa: "Restaurantes XYZ S.A." (CompanySession con ID_compania: 100)

  • Organización 1: "RXY Regional Centro" (BD: rest_centro)
    • Sucursal 1: Local Centro (ID_compania: 1)
    • Sucursal 2: Local Plaza (ID_compania: 2)
  • Organización 2: "RXY Regional Norte" (BD: rest_norte)
    • Sucursal 3: Local Norte (ID_compania: 3)
    • Sucursal 4: Local Costa (ID_compania: 4)
  • Organización 3: "RXY Regional Sur" (BD: rest_sur)
    • Sucursal 5: Local Sur (ID_compania: 5)

    • Creada desde CompanySession.sql.stub

⭐ Soluciones Propuestas

Opción 1: Tabla Intermedia user_branches (RECOMENDADA)

Ventajas:

  • Control granular: asignar sucursales específicas por organización
  • Flexible: Juan puede ver sucursales 1,2 de Org1 y solo 4 de Org2
  • Escalable: fácil agregar/quitar sucursales
  • Auditable: registrar quién tiene acceso a qué

1. Crear tabla intermedia:

php artisan make:migration create_user_branches_table

// Migration
Schema::create('user_branches', function (Blueprint $table) {
    $table->id();
    $table->unsignedBigInteger('user_id');
    $table->unsignedBigInteger('organization_id');
    $table->integer('branch_id'); // ID_compania
    $table->timestamps();
    
    $table->foreign('user_id')->references('id')->on('users');
    $table->foreign('organization_id')->references('id')->on('organizations');
    
    // Índice único: un usuario no puede tener la misma sucursal duplicada
    $table->unique(['user_id', 'organization_id', 'branch_id']);
});

2. Modificar OrganizationService:

// app/Services/OrganizationService.php

/**
 * Obtiene los ID_compania (sucursales) asignados al usuario
 * en la organización actual
 * 
 * @return array
 */
public function getUserBranchIds(): array
{
    $organization = $this->getOrganization();
    $user = auth()->user();
    
    if (!$organization || !$user) {
        return [];
    }
    
    return DB::table('user_branches')
        ->where('user_id', $user->id)
        ->where('organization_id', $organization->id)
        ->pluck('branch_id')
        ->toArray();
}

/**
 * Verifica si el usuario tiene acceso a una sucursal específica
 * 
 * @param int $branchId
 * @return bool
 */
public function hasAccessToBranch(int $branchId): bool
{
    $allowedBranches = $this->getUserBranchIds();
    return in_array($branchId, $allowedBranches);
}

3. Crear Global Scope:

// app/Models/Scopes/BranchFilterScope.php

namespace App\Models\Scopes;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Scope;

class BranchFilterScope implements Scope
{
    /**
     * Filtra automáticamente por sucursales asignadas al usuario
     */
    public function apply(Builder $builder, Model $model)
    {
        if (!auth()->check()) {
            return;
        }
        
        $organizationService = app(\App\Contracts\OrganizationServiceContract::class);
        $branchIds = $organizationService->getUserBranchIds();
        
        if (!empty($branchIds)) {
            $builder->whereIn('ID_compania', $branchIds);
        }
    }
}

4. Aplicar a modelos:

// app/Models/SalesHeaderImp.php

use App\Models\Scopes\BranchFilterScope;

class SalesHeaderImp extends Model
{
    protected static function booted()
    {
        static::addGlobalScope(new BranchFilterScope);
    }
}

// Supervisor necesita ver consolidado de múltiples organizaciones
// Cada organización tiene múltiples sucursales

$totalSales = 0;
$salesByBranch = [];

foreach ($user->organizations as $org) {
    DB::connection()->useDatabase($org->database);
    
    // Obtener sucursales asignadas para esta organización
    $branchIds = $organizationService->getUserBranchIdsForOrg($org->id);
    
    $sales = SalesHeaderImp::withoutGlobalScope(BranchFilterScope::class)
        ->whereIn('ID_compania', $branchIds)
        ->get();
    
    foreach ($sales as $sale) {
        $salesByBranch[$sale->ID_compania] = ($salesByBranch[$sale->ID_compania] ?? 0) + $sale->Net_due;
        $totalSales += $sale->Net_due;
    }
}

return [
    'total' => $totalSales,
    'by_branch' => $salesByBranch
];

Conclusión

Arquitectura Correcta Identificada:

  • ✅ 1 Empresa Matriz = N Organizaciones
  • ✅ 1 Organización (BD propia) = N Sucursales (ID_compania)
  • ✅ Usuario necesita asignación granular de sucursales

Solución Recomendada:

  1. Crear tabla user_branches para asignación granular
  2. Implementar BranchFilterScope global
  3. Aplicarlo a los 43 modelos con ID_compania
  4. Migrar asignaciones existentes (por defecto: todas las sucursales)
  5. Desplegar gradualmente con monitoreo
