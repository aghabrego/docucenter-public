    API QuickBooks - Facturación Electrónica

    📊 Integración QuickBooks Online

    Esta API permite la integración completa con QuickBooks Online para la emisión de facturas electrónicas en Panamá, procesando automáticamente las transacciones con validaciones DGI y emisión de CUFE.

    🎯 Descripción General

    La API de QuickBooks permite crear y emitir facturas electrónicas basadas en datos provenientes de QuickBooks Online, integrando completamente el sistema ERP con la facturación electrónica panameña.

    Características Principales

    • 🔄 Procesamiento Asíncrono: Manejo de trabajos en cola para operaciones de alta carga
    • 📋 Validación Completa: Validaciones exhaustivas de estructura QuickBooks y requisitos DGI
    • 🛡️ Manejo de Errores: Sistema robusto con reintentos automáticos y logging detallado
    • 💰 Soporte Multi-Moneda: Compatibilidad con diferentes divisas
    • 🏢 Multi-Organización: Soporte para múltiples empresas
    • 📊 Seguimiento de Transacciones: Trazabilidad completa del proceso

    🔐 Configuración y Autenticación

    Headers Requeridos

    Authorization: Bearer {token}
Content-Type: application/json
Accept: application/json
X-Organization-Id: {organization_id}

    Middleware

    • check.activate.organization: Valida que la organización esté activa
    • auth:api: Autenticación via Bearer Token

    🔗 Endpoint Principal

    POST /api/v1/fe/create_sale_quickbooks

    Controller: FeController::createSaleQuickbooks
    Queue: sales (procesamiento asíncrono)
    Timeout: 300 segundos
    Reintentos: 3 intentos máximo

    ✅ Validaciones

    Campos Principales

    Campo Tipo Requerido Validación
    Invoice array ✅ Estructura principal requerida
    Invoice.TotalAmt numeric ❌ Monto total ≥ 0
    Invoice.TxnDate date ❌ Formato: Y-m-d
    Invoice.DueDate date ❌ Formato: Y-m-d

    Validaciones de Cliente

    Campo Validación Ejemplo
    CustomerRef.RUC Max 50 caracteres 12345678-1-123456
    CustomerRef.TIPO Valores: 1, 2 1 (Jurídica), 2 (Natural)
    CustomerRef.TIPO_RECEPTOR 01, 02, 03, 04, 1, 2, 3, 4 01 (Contribuyente)
    CustomerRef.PrimaryEmail Email válido cliente@empresa.com

    Validaciones de Dirección

    📍 Código Postal Panameño

    El código postal debe seguir el formato panameño: #-#-# (ejemplo: 8-8-7)

    Validaciones de Líneas de Producto

    Campo Validación Descripción
    Line.*.DetailType Enum específico SalesItemLineDetail, SubTotalLineDetail, etc.
    Line.*.Amount numeric ≥ 0 Monto de la línea
    Line.*.LineNum integer ≥ 1 Número de línea (auto-generado si no se proporciona)

    ⚡ Procesamiento Asíncrono

    Job: CreateSaleQuickBooksJob

    • Cola: sales
    • Timeout: 300 segundos
    • Reintentos: 3 intentos máximo
    • Manejo de Fallos: Logging crítico y notificaciones

    Flujo de Procesamiento

    1. Recepción Request → Validación
2. Dispatch Job → Cola 'sales'
3. Respuesta Inmediata → HTTP 200
4. Procesamiento Asíncrono:
   ├── Configurar Organización
   ├── Guardar Transacción
   ├── Crear Sales Header
   ├── Validar Contador de Intentos
   └── Emitir Factura Electrónica

    Control de Reintentos

    ⚠️ Limitación de Intentos

    El sistema controla automáticamente los reintentos mediante AttempCounter. Si se exceden 2 intentos, se lanza una excepción para evitar duplicación de facturas.

    🚨 Manejo de Errores

    Tipos de Errores

    ❌ Errores de Validación

    • 422 Unprocessable Entity: Datos inválidos en el request
    • Campos faltantes: Estructura Invoice requerida
    • Formato incorrecto: Fechas, emails, códigos postales

    ⚠️ Errores de Procesamiento

    • CUFE Duplicado: La factura ya existe (no es error crítico)
    • Límite de Intentos: Se excedieron los 3 reintentos
    • Timeout: Procesamiento excedió 300 segundos

    Códigos de Error Específicos

    Código Descripción Acción Recomendada
    QB_001 Estructura Invoice inválida Verificar formato JSON
    QB_002 RUC inválido Verificar formato RUC panameño
    QB_003 Tipo receptor inválido Usar: 01, 02, 03, 04
    QB_004 Código postal inválido Usar formato: #-#-#
    QB_005 CUFE ya existe Factura ya procesada (OK)
